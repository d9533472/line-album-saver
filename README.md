# LINE 相簿批次儲存（LineAlbumSaver）

把電腦版 LINE 群組裡的相簿一本一本自動「儲存全部」，每本相簿存成一個子資料夾，存完自動核對張數。

全部在自己電腦上執行（用 Windows 內建 OCR 辨識文字），不上傳任何照片。只有你按「意見回饋」送出時才會連網，把你填的內容寄給作者。

> 非 LINE 官方工具，與 LINE Corporation 無關。使用前請先閱讀下方〈免責聲明〉。

## 下載

到 [Releases](../../releases/latest) 下載 `LineAlbumSaver.exe`，直接執行即可，不用安裝。

- 需要 Windows 10 / 11（64 位元）與電腦版 LINE。
- 第一次執行如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
- OCR 需要系統有繁體中文語言（一般中文版 Windows 已內建）。

## 使用步驟

1. 在電腦版 LINE 打開群組的「相簿」總覽。
2. 開工具 → 選視窗：名稱後面寫「相簿」的才是總覽（例如「家族群組 相簿」）；一般對話視窗會標「（一般對話視窗）」，不能選來執行。
3. 選儲存資料夾（會記住上次的位置）。
4. 按「① 快速掃描相簿」。工具會縮小，從總覽最上面捲到最底，只讀每本相簿的名稱與張數，**不會點開任何相簿**。
5. 在清單勾選要下載的相簿（有「全選」「全不選」）。儲存位置已經有同名資料夾、張數也相符的，會標「已下載」並預設不勾。
6. 按「② 下載勾選的相簿」。工具逐本捲到該相簿的位置，先確認名稱跟掃描時一樣，再：點名稱 → 單本相簿右上 ⋮ → 儲存全部 → 自動填入子資料夾 → 等檔案存完 → 關掉單本視窗 → 下一本。下載成功的會自動取消勾選，失敗的保留勾選，可以直接再按一次重跑。
7. 執行中不要動滑鼠鍵盤，**F8** 隨時停止。

## 刪除已下載的相簿（手動確認）

8. 清單的「刪除」欄只有**張數完全相符**的相簿才勾得到（「完成 ✔」、「已下載（張數相符）」或「略過（已下載過，張數相符）」）。
9. 勾好後按「🗑 刪除勾選的相簿」，確認視窗會列出每本名稱與張數，要**輸入「刪除」**才會執行。
10. 工具由清單最下面往上逐本：確認位置上的名稱沒變 → 打開相簿 → 再核對標題與張數＝資料夾檔案數（不符就不刪）→ ⋮ → 「刪除相簿」（只認文字，不靠位置）→ 按 LINE 確認視窗中文字剛好是「刪除／確定」的按鈕（找不到就取消）。
11. 刪除後群組裡所有人都看不到，無法復原。第一次建議只勾一本不重要的相簿試刪。

## 核對機制

- 每本讀單本相簿上的「N張照片」，存完後數資料夾內的檔案數比對：綠＝相符、紅＝不完整/失敗。
- 結束時在儲存資料夾產生 `LINE相簿下載核對_日期時間.csv`。
- 「重新核對張數」可隨時重新數一次並另存核對表；雙擊表格列開啟該資料夾。
- 資料夾已存在且張數相符 → 自動略過；不符 → 另建 `名稱 (2)` 重新下載。
- 掃描後如果有人新增或刪除相簿，位置會跑掉：下載前會比對名稱，不一致就標失敗並提示重新掃描，不會點錯本。

## 意見回饋

標題列右上的「✉ 意見回饋」可以回報問題或提建議，送出後會寄信給作者。Email 選填（想收到回覆再填）；「附上執行紀錄」預設不勾，勾了才會一起送出（內含相簿名稱與資料夾路徑）。

## 疑難排解

LINE 改版可能讓工具抓不到按鈕。可以先跑只讀不點的診斷：

```
LineAlbumSaver.exe --probe 輸出.txt
```

會列出視窗判斷與畫面上辨識到的相簿名稱、張數、選單。

## 技術備註

- 視窗類型用 UI Automation 類別判斷：`GroupHomeWindow`＝相簿總覽、`AlbumDetailWindow`＝單本相簿、`LcContextMenu`＝⋮ 選單、`ChatWindow`＝對話視窗。
- 總覽捲軸用 RangeValue 直接設定，並用捲軸值換算每本相簿的絕對位置，避免重複或漏掉。
